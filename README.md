# 📊 Digital Store Annual Sales Dashboard 2025

An interactive **Digital Store Annual Sales Dashboard** developed using Microsoft Excel to analyze sales, orders, customer demographics, order status, sales channels, product categories, and state-wise performance.

The dashboard uses **PivotTables, PivotCharts, and Slicers** to make the analysis interactive and easy to explore.

## 📈 Dashboard Insights

The dashboard provides a visual analysis of:

- Monthly sales and order trends
- Sales distribution between men and women
- Order status such as Delivered, Cancelled, Returned, and Refunded
- Top-performing states based on sales
- Orders by different age groups and genders
- Orders across different sales channels
- Product category performance

## 🎛️ Interactive Filters

The dashboard includes interactive **Slicers** that allow users to filter the analysis by:

- Month
- Sales Channel
- Product Category

When a filter is selected, the connected PivotTables and charts update accordingly.

## ▶️ How to Use

1. Download the `Digital_Store_Annual_Dashboard.xlsx` file.
2. Open it using **Microsoft Excel**.
3. Go to the **Digital Store Annual Dashboard** sheet.
4. Use the Slicers to filter the data.
5. Explore the updated charts and analysis.

## 📌 Important Note

The dashboard is fully interactive when opened in **Microsoft Excel**.

The dashboard screenshot is provided for preview purposes, while the Excel workbook contains the actual **PivotTables, PivotCharts, data, and interactive Slicers**.

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into an interactive and visually appealing dashboard that helps users understand sales performance and identify important business insights quickly.
